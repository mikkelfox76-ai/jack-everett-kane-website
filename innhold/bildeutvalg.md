# Bildeutvalg

Godkjente bilder ligger i `bilder/originaler/`. Claude Code skal lage optimaliserte WebP-versjoner i `bilder/` og ikke endre originalene.

## Hero / toppbanner (bredt 2660×1140)
- **Hovedvalg:** `hero-gitar-mikrofon-2.jpg`. Spotlys øverst til venstre og god plass til navnet på venstre side.
- Alternativ: `hero-gitar-mikrofon-1.jpg`

## Om Jack (portrett)
- **Hovedvalg:** `jack-portrett-oransje-briller.png`. Rett mot kamera, og de oransje brillene er signaturen hans.
- Alternativer: `jack-portrett-svarte-briller.png`, `jack-oransje-briller-orken.png`

## Seksjonsbakgrunner og stemningsbilder
- `jack-regn-landevei.jpg`: bak diskografi eller video
- `jack-kraker-sno.png`: bak kontakt/følg
- `jack-banjo-prarie.png`: ekstra bilde
- `jack-kirke-kvadrat.png`: kvadratisk, fungerer godt som Open Graph-/delebilde
- `jack-gitar-mikrofon.jpg`: nesten kvadratisk, kan brukes som reserve
